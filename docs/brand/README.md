# MOAP brand

- **Icon** (`icon.svg`): one central node with seven around it, for the orchestrator and its seven specialists.
- **Palette:** violet `#6d4fd8` (light) / `#a78bfa` (dark), ink `#1d1b26`, paper `#ffffff`, night `#0f0e14`, done-green `#1f8a5b`.
- **Type:** the system UI font stack; no web fonts are shipped.
- **Social preview** (`social-preview.png`, 1280×640): upload it under Settings → General → Social preview.

Sources are HTML (`social-preview.html`, `../images/how-it-works.html`). After changing one, run `node docs/images/render.mjs` from the repository root.
